# PowerPoint_Presentation

Presentations and technical notes on digital IC design, signal processing, and control algorithms. Welcome, and feel free to explore!

## Topics

- [DFT design](DFT%E8%AE%BE%E8%AE%A1_9.pdf).
- [RTL design methods](RTL%E8%AE%BE%E8%AE%A1%E6%96%B9%E6%B3%95_5.pptx) and [design and scripting guidelines](RTL%E8%AE%BE%E8%AE%A1%E4%B8%8E%E8%84%9A%E6%9C%AC%E8%A7%84%E8%8C%83.pdf).
- [FFT architecture](FFT%E6%9E%B6%E6%9E%84%E8%AE%BE%E8%AE%A1_6.pptx), fixed-point modeling, and code generation.
- [Field-oriented control](FOC%E7%AE%97%E6%B3%95_1.pptx), Kalman filtering, observers, and S-functions.
- [Model predictive control and quadratic programming](MPC_QP_3.1.pptx), matrix inversion, and a quadratic-programming flow diagram.

## Viewing the Files

Browse the PDFs on GitHub or download them. Open `.pptx` files in PowerPoint or a compatible viewer, and `.vsdx` files in Visio or a compatible viewer.
